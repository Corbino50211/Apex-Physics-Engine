# Apex Physics Engine

A modular Unity physics framework from PancakeDevs for physical bodies, grabbing, navigation, and physics-driven NPC behavior.

## Current package version

`0.0.5`

## Included systems

- `ApexBody` and reusable physics profiles
- force-driven grabbing and authored grab points
- automatic NavMesh baking
- physics-driven NPC movement
- Idle, Wander, and Chase NPC behavior modes
- hard-impact retaliation with timed return to wandering

Use the **Apex Physics Engine** menu in Unity's top bar for setup tools.
