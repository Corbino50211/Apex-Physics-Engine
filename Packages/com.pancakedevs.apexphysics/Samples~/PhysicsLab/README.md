# Apex Physics Lab

The Physics Lab will be the permanent validation scene for Apex Physics Engine.

The first scene should contain:

- a floor and reset area
- a light cube using an Apex physics profile
- a heavy cube using a different profile
- a ramp for collision and sleeping tests
- an impulse launcher for repeatable force tests
- a runtime readout for velocity, mass, and impact data

Later milestones will add physical hands, one-handed and two-handed grabbing, mechanisms, a physical player, and active-ragdoll NPCs.
